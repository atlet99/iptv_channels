# iptv_channels

Ready-to-use IPTV playlist files for players (M3U / XMLTV EPG / XSPF).

## Files

| File | Purpose |
|---|---|
| `lgiptv.m3u8` | Channel playlist (M3U, UTF-8) |
| `lgiptv-epg.xml` | Program guide in XMLTV format |
| `lgiptv-epg.xml.gz` | Gzip copy of the EPG, for players that prefer it |
| `lgiptv.xspf` | Same channels in XSPF (VLC) format |

Stream links in the playlist are time-limited by the upstream services, so
a stale download may contain expired URLs — check the repository for a
fresher commit.
